# Changelog

## 0.1.1 - 2026-07-27

### Fixed

- Resolve the Unicode Win32 entry points used for monitor detection, window closing, and the scoped Escape hook.

## 0.1.0 - 2026-07-27

### New

- Open Claude and Codex usage pages side by side with `Ctrl+Alt+U`.
- Run as a tray-only, single-instance Windows application.
- Close tracked popups with the global toggle, scoped Escape key, tray menu, or app exit.
- Configure usage URLs, Chrome location, monitor selection, window size, spacing, and startup.
- Install per user or run a self-contained portable build.
