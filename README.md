# CC Usage Tracker

Open Claude and Codex usage pages side by side from the Windows system tray.

[Download the latest release](https://github.com/chieaid24/cc-usage-tracker/releases/latest)

Requires Windows 10 or 11 x64 and Google Chrome. Download `CCUsageTracker-Setup-x64.exe`, run it, then press `Ctrl+Alt+U`. Windows may show a SmartScreen warning because the release is unsigned.

| Action | Control |
| --- | --- |
| Open or close usage | `Ctrl+Alt+U` |
| Close while a usage window is focused | `Esc` |
| Open the tray menu | Right-click the tray icon |

For portable use, extract `CCUsageTracker-win-x64.zip` and run `CCUsageTracker.exe`.

CC Usage Tracker does not scrape pages, read account data, require API keys, or send telemetry.
