CC Usage Tracker

Run CCUsageTracker.exe. The app appears in the Windows system tray.
Press Ctrl+Alt+U to open or close the Claude and Codex usage pages.

Requirements:
- Windows 10 or Windows 11, x64
- Google Chrome

The portable build enables Start with Windows on first launch. Clear that
setting from the tray menu or Settings if you do not want it.

Project: https://github.com/chieaid24/cc-usage-tracker
